# Adding a listening lesson

A lesson is one folder under `content/` holding `listening.mp3`, `source.json`
(written by hand, the source of truth) and `listening.json` (generated — never edit it,
edit `source.json` and rebuild). The server picks up every folder that has a
`listening.json`; no registry to update.

```
content/jlpt/n2/2024-07/
  listening.mp3     audio (CBR — the `audio` step makes sure)
  source.json       script, translations, choices, answers
  listening.json    generated by `build`
```

## Steps

```bash
cd backend
T=content/jlpt/n2/2024-07

python3 scripts/lesson/lesson_tool.py audio $T        # VBR → CBR (browsers seek VBR badly)
python3 scripts/lesson/lesson_tool.py transcribe $T   # ~15–25 min for a 40 min test
#   → .work/jlpt/n2/2024-07/transcript.txt  (read this to write source.json)
#   write $T/source.json
python3 scripts/lesson/lesson_tool.py build $T        # align lines to audio → listening.json
python3 scripts/lesson/lesson_tool.py speakers $T     # pitch per line: catches swapped 男/女 labels
python3 scripts/lesson/lesson_tool.py verify $T       # re-listen each sentence, flag mismatches
npx tsx packages/content-schema/src/cli.ts content     # schema + rules check
```

`build` prints one line per dialogue; `LOW lines [(n, 0.4)]` means line *n* barely matched the
audio — usually a typo in `source.json` or a line the speaker did not actually say.
`speakers` prints the median pitch of every line next to its label and marks `male` lines above
~200 Hz and `female` lines below ~170 Hz. Men sit around 110–170 Hz, women 220–300 Hz; a flagged
run of lines usually means the turns are assigned to the wrong person — which can change the
answer (「女の人は何を書きますか」), so fix the labels, not the threshold.
`verify` re-transcribes every sentence clip on its own; clips below 0.75 are worth a listen.
If two sentences run together with no pause and the split lands wrong, pin it with
`manual_boundaries` (see below) and rebuild.

Requirements: `ffmpeg`, `pip install faster-whisper numpy`, Node for the validator.
Scratch output (ASR words, audio backup, reports) lives in `backend/.work/` (git-ignored).

## source.json

```jsonc
{
  "id": "jlpt-n2-2024-07",                       // unique lesson id
  "source": { "type": "jlpt", "level": "N2", "year": 2024, "month": 7 },
  "status": "published",                         // draft | verified | published (only published is listed)
  "review_note": "…",                            // optional: shown to reviewers, sets review_required
  "speakers": {                                  // only for ids other than narrator/male/female/choice_N
    "speaker": { "ja": "話し手", "vi": "Người nói", "en": "Speaker" },   // 問題3/4 monologue, statement
    "male2":   { "ja": "男2",   "vi": "Nam 2",     "en": "Man 2" }       // two men in one dialogue
  },
  "manual_boundaries": { "jlpt-n2-2024-07-m2-q4-s3": 828.3 },  // optional: start (s) of that line
  "sections": [
    {
      "no": 1,                                   // 問題1
      "questions": [
        {
          "no": 1,                               // 1番
          "prompt": { "ja": "男の学生はこの後まず何をしますか。", "vi": "…", "en": "…" },
          "choices": [                           // printed options (問題1, 問題2, 問題5 last item)
            { "id": "1", "ja": "…", "vi": "…", "en": "…" }
          ],
          "image": { "url": "https://res.cloudinary.com/…", "alt": { "ja": "…", "vi": "…" } },  // optional booklet figure
          "answer": "3",                         // omit until known → question is dictation-only
          "evidence": [7, 8],                    // line numbers (1-based) that decide the answer
          "why": { "1": "Sai: …", "2": "Sai: …", "3": "Đúng: …", "4": "Sai: …" },  // one per choice (required)
          "lines": [                             // everything spoken, in order: [speaker, ja, vi, en?]
            ["narrator", "大学で女の学生と男の学生が話しています。", "Ở trường đại học, …"],
            ["female", "中村くん、…", "Nakamura, …"]
          ]
        }
      ]
    }
  ]
}
```

- **Spoken options** (問題3, 問題4, 問題5 1番): write them as lines with speaker `choice_1`,
  `choice_2`… and leave out `"choices"`; the options are taken from those lines. Do not include
  the spoken number 「1、」 in the text.
- **Several questions on one dialogue** (問題5 last item, 質問1/質問2): put the dialogue in
  `lines` and the questions in `"sub": [{ "prompt", "choices", "answer", "evidence", "why" }, …]`.
  Each sub-question keeps printed labels (`"mode": "text"` is the default when `choices` is given).
- **Pictures in the booklet**: crop the figure, upload it with
  `node scripts/lesson/upload_image.mjs <png> jlpt/<level>/<yyyy-mm>/m<s>-q<n>-figure` (Cloudinary
  credentials from `backend/.env`) and put the printed URL in `"image"`. Picture options where each
  choice is its own image: `"choices": [{ "id": "1", "ja": "…", "image": { "url": "…" } }]` with `"mode": "image"`.
- One line = one sentence as spoken; that is the unit learners dictate. Split long turns at 。
- Leave out section instructions (問題1では…) and the practice example (例) — alignment skips them.
- Line ids come out as `<lesson>-m<section>-q<question>[-sq<k>]-s<line>`.
